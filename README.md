# Multi-Cloud Blue Team Analysis

This repository documents my hands-on experience and takeaways from the **Multi-Cloud Blue Team Analyst (MCBTA)** certification. The course focused on performing blue team operations across Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP), simulating real-world security incidents in a multi-cloud environment.

* * *

## Overview

The MCBTA certification is a beginner-friendly, fully practical program designed to introduce learners to core cloud security practices. It covers centralized logging, threat detection, and incident response across multiple cloud platforms.

![cd12b4845641bc32cae1909f53f6bf1d.png](:/3556a2ae3451458cb9d4c6df0b190e96)

This project demonstrates:

- Deployment of a centralized SIEM (ELK stack) for multi-cloud log ingestion and monitoring.
    
- Investigation of 15+ simulated cloud breach scenarios using TheHive.
    
- Completion of 30+ hands-on blue team challenges involving log analysis and threat detection.
    
- Earning the MCBTA certification as proof of foundational cloud defense skills.
    

* * *

## Key Components

- **Cloud Breach Investigations**  
    Logs from AWS, Azure, and GCP were analyzed to detect signs of lateral movement, privilege escalation, data exfiltration, and more.
    
- **Centralized Logging and Monitoring (SIEM)**  
    Elastic Stack was deployed locally to ingest and visualize logs from different cloud sources.
    
- **TheHive Case Management**  
    Used TheHive to manage investigations and correlate artifacts across breach scenarios.
    
- **Capture the Flag (CTF) Challenges**  
    Each scenario included a set of flags to validate understanding of log-based threat detection techniques.
